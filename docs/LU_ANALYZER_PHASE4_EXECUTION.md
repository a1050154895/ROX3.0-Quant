# 卢式分析器升级 - 第四阶段（P3）实施说明

## 本阶段目标
1. 从“单票分析”升级到“组合建议”。
2. 引入组合层风险约束（单票上限、总仓上限、现金比例）。
3. 保持 v2/v3 能力兼容并给出可执行组合输出。

## 已实施内容
- 协议版本升级到 `lu-analyzer-v4`。
- `predict-v2` 延续并增强：
  - 市场状态 `market_regime`
  - 自适应权重 `adaptive_weights`
- 新增 `POST /api/lu-prediction/portfolio-v2`：
  - 输入代码池
  - 内部复用 `scan-v2` 排序
  - 输出组合权重建议与风控摘要

## Phase-4 能力点
- 组合构建：按综合评分选择候选并分配权重
- 风控约束：
  - `single_max`（单票上限）
  - `portfolio_max`（组合总仓上限）
  - 自动计算 `cash_weight`
- 与市场状态联动：熊市自动降风险敞口

## 下一步建议
1. 接入真实协方差矩阵做风险平价/最小方差优化。
2. 增加行业暴露约束与相关性惩罚项。
3. 加入组合回测与调仓频率评估。


## Phase-5 增强（可选）
- 新增 `POST /api/lu-prediction/portfolio-v3`
- 在 v4 规则分配基础上，增加收益率协方差矩阵优化
- 新增桶级暴露约束（`bucket_cap`），限制同一市场桶集中度
- 输出协议版本 `lu-analyzer-v5`
