# ROX 3.0 用户手册

## 1. 系统概述

ROX 3.0 是一款功能强大的量化交易系统，集成了市场分析、策略回测、AI分析等多种功能，为投资者提供全方位的量化交易工具。

### 1.1 核心功能

- **市场看板**：实时行情、资金流向、板块轮动
- **个股诊断**：技术分析、基本面分析、AI推演
- **策略回测**：多种量化策略的历史回测
- **知识库**：文档管理和智能搜索
- **交易系统**：模拟交易和实盘对接
- **宏观仪表盘**：宏观经济数据监控
- **策略超市**：丰富的量化策略供用户选择和使用

### 1.2 技术架构

- **前端**：现代化的Web界面，响应式设计，支持移动端
- **后端**：FastAPI框架，高性能API服务
- **数据来源**：东方财富网、Tushare、AKShare、BaoStock等
- **AI集成**：支持DeepSeek、通义千问等大语言模型

## 2. 安装与配置

### 2.1 系统要求

- **操作系统**：Windows 10+、macOS 10.15+、Linux
- **Python**：3.8+
- **内存**：至少4GB
- **存储空间**：至少1GB

### 2.2 安装步骤

1. **克隆代码库**
   ```bash
   git clone <repository-url>
   cd rox3.0
   ```

2. **创建虚拟环境**
   ```bash
   python -m venv .venv
   ```

3. **激活虚拟环境**
   - Windows: `.venvcriptsctivate`
   - macOS/Linux: `source .venv/bin/activate`

4. **安装依赖**
   ```bash
   pip install -r requirements.txt
   ```

5. **配置环境变量**
   复制 `.env.example` 文件为 `.env` 并配置相关参数

### 2.3 环境变量配置

**必填配置**：
- `AI_API_KEY`：AI模型API密钥（DeepSeek、通义千问等）
- `AI_BASE_URL`：AI模型API地址

**推荐配置**：
- `TUSHARE_TOKEN`：Tushare API密钥，用于获取A股数据

**可选配置**：
- `ALLTICK_TOKEN`：AllTick API密钥，用于获取实时行情数据

## 8. 故障排除

### 8.1 常见问题

#### 8.1.1 数据加载失败

**原因**：
- API密钥配置错误
- 网络连接问题
- 数据源服务异常

**解决方案**：
- 检查API密钥配置
- 检查网络连接
- 尝试使用备用数据源

#### 8.1.2 AI功能无法使用

**原因**：
- AI API密钥未配置
- AI BASE URL设置错误
- 网络连接问题

**解决方案**：
- 在 `.env` 文件中配置 `AI_API_KEY` 和 `AI_BASE_URL`
- 检查网络连接
- 尝试切换AI模型

#### 8.1.3 策略执行失败

**原因**：
- 策略代码错误
- 数据格式问题
- 参数设置不当

**解决方案**：
- 检查策略代码
- 验证数据格式
- 调整策略参数

## 11. 安全注意事项

### 11.1 API密钥安全

- **不要分享API密钥**：API密钥是敏感信息，不要分享给他人
- **使用环境变量**：通过 `.env` 文件配置API密钥，不要硬编码在代码中
- **定期更换密钥**：定期更换API密钥，提高安全性

### 11.2 数据安全

- **备份重要数据**：定期备份重要的策略和回测数据
- **保护个人信息**：不要在系统中存储敏感的个人信息
- **使用安全连接**：在公共网络中使用HTTPS连接

## 12. 常见问题解答

### 12.1 系统要求

**Q**: 系统需要什么样的硬件配置？
**A**: 至少4GB内存，1GB存储空间，推荐8GB以上内存以获得更好的性能。

### 12.2 数据源

**Q**: 系统使用哪些数据源？
**A**: 系统集成了东方财富网、Tushare、AKShare、BaoStock等多种数据源，可根据需要配置。

### 12.3 AI功能

**Q**: AI功能需要什么样的配置？
**A**: 需要配置AI API密钥，推荐使用DeepSeek或通义千问等模型。

### 12.4 策略回测

**Q**: 如何提高策略回测的速度？
**A**: 可以减少回测周期、优化策略代码、使用更高效的数据源。

### 12.5 实盘交易

**Q**: 系统支持实盘交易吗？
**A**: 系统支持模拟交易，实盘交易需要额外配置和对接。

### 13.4 术语解释

- **策略**：一套定义好的交易规则和逻辑
- **回测**：使用历史数据测试策略的表现
- **夏普比率**：衡量投资回报与风险的比率
- **最大回撤**：投资组合从峰值到谷值的最大损失
- **Alpha**：投资组合相对于基准的超额收益
- **Beta**：投资组合相对于基准的波动性
